# Make Knowledge Cards

把用户提供的文章提炼成 5~8 张知识卡片，每张卡片聚焦一个知识点，方便复习与记忆。只处理用户已给出的文本，不获取额外信息。

## 输入

- 粘贴的文本：直接使用。
- 本地文件：读取 `.md` / `.txt` 文件（其他格式请用户先转为文本）。
- 不支持：网页链接、PDF、Anki 导入、图形界面——明确告知用户，不做变通。

## 步骤

1. 通读全文，圈出候选知识点：可独立成立、值得单独记忆的概念、原理、方法、结论、数据。
2. 去重合并：同一知识点重复出现只保留一张；同一主题下的一组并列要点合并进一张卡。
3. 选最重要的 5~8 个知识点（按对读者的价值排序，与原文出现顺序无关）。
4. 逐卡写出四要素，按「输出格式」输出。

## 卡片四要素

| 要素 | 要求 |
|------|------|
| 标题 | 一句话点明知识点，≤ 20 字 |
| 核心知识 | 1~3 句最精炼的要点，忠于原文 |
| 简明解释 | 用更通俗的话展开，让没读过原文的人也能理解 |
| 例子或自测 | 一个具体例子，或一道自测题（附答案）；二选一 |

## 硬性规则

- **一张卡片只讲一个知识点**，卡与卡之间不重叠。
- **不编造**：不添加原文没有的信息、数据、结论；原文含糊就保持含糊。
- **例子**：允许自拟演示性例子，但不得虚构原文中的数据或事件，也不得暗示例子出自原文；自测题答案必须来自卡片内容。
- **不凑数**：有效知识点不足 5 个时按实际数量输出，并在开头用一行说明；超过 8 个只保留最重要的 8 张。
- 语言跟随原文（原文中文则卡片中文）。
- 只输出卡片 Markdown（数量不足的说明除外），不要额外总结或过程叙述。

## 输出格式

```markdown
## 卡片 1｜<标题>

**核心知识**：…

**简明解释**：…

**例子/自测**：…
```

连续输出卡片，编号从 1 开始。

## 常见错误

| 错误 | 修正 |
|------|------|
| 为凑满 5 张，把次要内容做成卡 | 宁少勿多，并说明数量不足 |
| 把并列要点拆成多张卡 | 同主题要点合并为一张 |
| 卡与卡内容重叠 | 每张只保留该知识点独有的内容 |
| 用原文没有的数据举例 | 例子不得引入新事实 |
